# Final_Year_Project_RON97

This project focuses on the analysis and forecasting of RON97 petrol prices in Malaysia using time series analysis. Weekly RON97 price data from March 2017 to April 2026 are analyzed to identify price trends and patterns, as well as to examine the relationships between RON97 prices, Brent crude oil prices, and the USD/MYR exchange rate.

Two forecasting models, **Autoregressive Integrated Moving Average (ARIMA)** and **Autoregressive Integrated Moving Average with Exogenous Variables (ARIMAX)**, are developed and compared to evaluate their forecasting performance. Model accuracy is assessed using Mean Absolute Error (MAE), Mean Absolute Percentage Error (MAPE), and Root Mean Squared Error (RMSE).

The analysis is conducted using R, with the aim of identifying a suitable time series model for forecasting RON97 petrol prices in Malaysia.
